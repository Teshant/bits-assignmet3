# Question 1 – Explanation of Commands

## mkdir submissions

Created the `submissions` directory to store the sample student submission files.

## mkdir backup

Created the `backup` directory where unique files are copied after duplicate detection.

## echo "Operating Systems Assignment" > submissions/student1.txt

Created the first sample submission file with the given content.

## cp submissions/student1.txt submissions/student2.txt

Copied `student1.txt` to create a duplicate file for testing duplicate detection.

## echo "Linux Lab Assignment" > submissions/student3.txt

Created another sample submission with different content so it is treated as a unique file.

## chmod +x solution.sh

Made the shell script executable.

## ./solution.sh

Executed the shell script to process all submission files, detect duplicates using MD5 hashes, back up unique files, generate a report, and log any errors.

## cat report.txt

Displayed the summary report generated by the script.

## cat errors.log

Displayed the error log. The file remained empty because no errors occurred during execution.

## ls backup

Verified that only the unique files (`student1.txt` and `student3.txt`) were copied into the backup directory.
